# Visual orgânico aprovado

Estudo v4 aprovado pelo João: formas curvas, pupila preta com foco, boca/arcada, sombra e atuação. Está autocontido nesta pasta; os protótipos anteriores estão no histórico do Git. `atuacao-base.mjs` preserva a referência necessária ao comparativo.

Em animacoes/: `npm run test:visual`. Para renderizar o estudo: `node docs/visual/renderizar.mjs`. O rig de produção é `motor/personagem/`, não este estudo. Não executar o antigo preparador da v3.
