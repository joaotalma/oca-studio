# Referências

Material de estudo vindo de fora: vídeos de outros criadores, pesquisas e referências visuais. O conteúdo é de terceiros e serve **só para análise**. Não copie personagens, trechos ou assets para os vídeos e mantenha o repositório privado.

| Pasta | O que tem |
|---|---|

| [`videos-analisados/13-referencias/analise-visual/`](videos-analisados/13-referencias/analise-visual/) | Para cada vídeo: cortes, movimento e panorama (json e jpg), mais os scripts que geraram a análise |

Até 2026-11-12, as 13 referências ficavam fora do git, em `plotline/.tmp/referencias-13/` e `plotline/render/transcricoes-referencias/`.
