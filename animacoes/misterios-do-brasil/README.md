# Mistérios do Brasil (nome a definir)

Canal de animação sobre fatos brasileiros inacreditáveis, com o gancho "Imagine...".

Por enquanto o material continua onde a engine espera:

- Configuração do canal: [`../canal/canal.md`](../canal/canal.md)
- Roteiros: [`../roteiros/`](../roteiros/) (Apagão 2001, Plano Collor, ET de Varginha e os outros)
- Render: `bash engine/montar.sh roteiros/<slug>`, rodado a partir de `animacoes/`

Quando o nome estiver definido, dá para mover os roteiros para cá, desde que a engine seja ajustada para o caminho novo.
