# Mistérios do Brasil (nome a definir)

Canal de animação sobre fatos brasileiros inacreditáveis, com o gancho "Imagine...".

| O quê | Onde |
|---|---|
| Configuração do canal, regras, resultados e voz | [`canal/`](canal/) |
| Roteiros (Apagão 2001, Plano Collor, ET de Varginha e outros) | [`roteiros/`](roteiros/) |
| Pautas, paletas e revisão v2 | [`radar/`](radar/) |
| Personagem narrador ("você", v4 aprovado) | [`personagens/`](personagens/) |

Render, rodado a partir de `animacoes/` no Git Bash:

```bash
bash motor/montar.sh series/misterios-do-brasil/roteiros/<slug>
```

`roteiros/_exemplo-chat` e `roteiros/_teste-ilustrado` são exemplos dos templates.
