# Personagens

Vazia até o canal definir um personagem fixo. Cada um terá:

- `<nome>.md`: o bloco de descrição imutável, colado igual em todo prompt
- `<nome>-ficha.png`: a ficha em fundo neutro, de frente e de perfil

Personagem novo é arquivo novo. Não edite uma ficha já usada em vídeo publicado.
